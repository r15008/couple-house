# 小日子 · 情侣共同小屋

这是一个手机端优先的情侣共同小屋原型，包含：

- 小屋装修主题：奶油小屋、海边夏天、森林晚安
- 共同宠物、心情、任务打卡
- 时光记录和心愿清单
- 情侣绑定邀请码界面
- 本地状态持久化
- 同一浏览器多标签页实时同步
- 通过 `server.js` 运行时的独立邀请码、持久化房间状态 API + SSE 实时同步

## 运行实时同步版

在这个目录打开终端执行：

```powershell
node server.js
```

然后访问 <http://localhost:8787/couple-house/>。打开两个浏览器窗口即可测试同一个房间的实时更新。

首次打开实时同步版会自动创建一个独立邀请码。把邀请码发给另一半，TA 在“我们”页面或头像入口输入后即可加入同一个房间。房间数据会写入 `data/rooms.json`，重启服务后仍然保留。

当前仍是开发版：邀请码没有登录鉴权，`data/rooms.json` 也不是生产数据库。正式上线时，需要换成 HTTPS、账号系统、数据库和权限校验。

## 公网部署

项目已经包含 `Dockerfile` 和 `render.yaml`，可以部署到支持 Docker 的云平台。以 Render 为例：

1. 把项目推送到自己的 GitHub 仓库。
2. 在 Render 选择这个仓库，并使用 `render.yaml` 创建服务。
3. 服务会自动生成公网 HTTPS 地址；把这个地址发给另一半即可访问。
4. `render.yaml` 已配置持久化磁盘，房间数据不会因服务重启丢失。

手机打开公网地址后，可以通过浏览器的“添加到主屏幕”安装成类似 App 的 PWA。
